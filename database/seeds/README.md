# Seeds

VIGÍA no incluye incendios, métricas ni predicciones de ejemplo. Los únicos seeds permitidos en
esta fase son catálogos estáticos de fuentes oficiales, una vez que su versión y licencia hayan
sido verificadas. Los datos de demostración deberán vivir en un entorno separado y llevar la
etiqueta visible `DATOS DE DEMOSTRACIÓN`.
