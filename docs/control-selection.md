# Selección de controles

Estado Fase 7: infraestructura disponible; controles reales congelados: **0**.

Una ventana se llama `NO_KNOWN_FIRE_CONTROL`, nunca `TRUE_NEGATIVE`. Antes de incorporarla debe
tener AOI/intervalo, método de selección preespecificado, cobertura de sensores, fuentes de
referencia y comprobaciones de exclusión. Se emparejará por región, estación, land cover,
meteorología y oportunidad de observación cuando esos datos sean reales y temporales.

Los hard negatives —industria, actividad agrícola o anomalías descartadas— requieren evidencia
oficial/documentada. No se etiquetan mirando una falsa alerta. Sin controles suficientes,
precision, F1 y tasa de falsas alertas permanecen `NO DISPONIBLE`.
